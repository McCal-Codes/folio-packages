# Sources people run

Folio can add any HTTPS source. These are ones worth knowing about; add yours with a pull request
(see [CONTRIBUTING.md](CONTRIBUTING.md)).

Folio doesn't read this file. Adding a source is always something you do by hand, and Folio shows you its key
fingerprint before it trusts it. A source being listed here is not a review of what's on it.

| Source | Who runs it | What's on it |
|---|---|---|
| `https://mccal-codes.github.io/folio-packages/` | McCal | This repo: packages people have sent in. |
